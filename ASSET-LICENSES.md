Sources verified 2026-11-04. CC0 permits raw redistribution; CC BY requires attribution and change notice. The in-app field guide includes beaver credit, source/license links and change notice. Future generated models need explicit plan/output rights verification before public raw-file redistribution.

The earlier `beaver.glb` remains preserved as a fallback; the runtime now loads `beaver-gobkit.glb`. ChubbyBeaver was inspected outside the shipped assets but not selected. Gobkit's source manifest explicitly labels both candidates CC0; the actual downloaded files have four separate named clips (`idle`, `walk`, `attack`, `dead`). Only idle/walk are assigned in the app; the greeting is original code, not a renamed attack.

The fetch script retrieves only these assets from the official author repositories/sites or the licensed model page's actual file URL. Kenney's signed link is resolved at download time. It does not execute downloaded code.
